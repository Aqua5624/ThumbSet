# ThumbSet （サムネ変更）

動画ファイルのサムネイルを iPhone 上で変更するアプリ。

- 動画を取り込む（ファイル / 写真アプリ）
- サムネイルを決める:
  - **画像を選ぶ**: 画像ファイル / 写真から選択
  - **フレーム指定**: スライダーで探して ◀▶ で1フレームずつ調整（先頭・中央・末尾のショートカット付き）
- 出力方法:
  - **カバー埋め込み**: mp4 の covr（attached pic）に画像を入れる。映像・音声は無加工で無劣化・高速
  - **先頭に差し込む**: 画像だけの動画（0.1〜1.0秒）を先頭に繋げる。先頭フレームからサムネイルを作るサービス向け（再エンコードあり）
  - **両方**: 上記の合わせ技
- サムネイル画像単体の共有（Rinha Drive のサムネイル設定用）、写真アプリへの保存、カバー画像の取り外しにも対応
